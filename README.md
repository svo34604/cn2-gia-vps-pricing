## 三网直连到底指什么，为什么它决定晚高峰体验

三网直连说的是三条回程线路：中国电信CN2 GIA、中国联通Premium（官方页面标注AS10099，第三方资料也常写作AS9929）、中国移动CMIN2。三者都是各家运营商拿钱砸出来的优质跨网通道，其中CN2 GIA的IP transit单价最高，搬瓦工自己的说明里写的是“每兆比特高达$120”——这个成本直接解释了为什么GIA套餐贵、而普通线路便宜。

便宜的线路走的是什么？AS4134（163骨干）是便宜但拥挤的那条，AS4809 CN2 GT本来是用来解决拥堵的，但搬瓦工官方的原话很直白："since 2019, it has become pretty much as congested as AS4134"——也就是说，2019年之后CN2 GT和普通163线路已经一样挤了。这就是为什么“CN2”三个字不能只看表面：CN2特惠方案和CN2 GIA-E虽然名字里都有CN2，实际是两个层级的线路。

晚高峰的差距有多直观？2026年9月针对搬瓦工洛杉矶DC6机房的测试显示，对中国电信和中国联通的连接达到500–650 Mbit/s，丢包约0%；而普通国际线路在同一时段的丢包可以到30%以上。这就是三网直连和普通线路的真实差价所在。

> 提示：非高峰时段，CN2 GIA站点和普通站点的速度差距不大。三网直连买的本质上是晚高峰那几个小时的质量。

## 常见问题

**CN2和CN2 GIA是一回事吗？**
不是。CN2是电信AS4809网络的总称，其中GT层级自2019年起已经和普通163骨干一样拥挤，只有GIA层级才是高质量的专线通道。搬瓦工的CN2特惠方案走GT层级，CN2 GIA-E系列才走GIA。这也是“CN2套餐只要$49.99/年”和“GIA-E要$169.99/年”差价三倍多的原因。

这档套餐确实经常缺货，第三方评测把它列为搬瓦工的主要缺点之一。官方Telegram频道@BandwagonHostNews主要推送限量版套餐的补货，标准GIA-E档位缺货时只能等补货，一些第三方导购站提供库存实时监控页面，可以关注。补货窗口通常不长，热门档位看到有货建议尽快下手。

**买了香港套餐还能换机房吗？**
不能。香港和日本的CN2 GIA特惠套餐固定在各自机房，不支持迁移。想要机房灵活性就选GIA-E系列——11个机房随时免费迁，数据不丢。反过来，如果预算有限又想用香港节点，可以买GIA-E然后迁到香港机房，成本比直接买香港特惠套餐低好几倍。

**三网直连对移动用户也有效吗？**
有效，但要看机房。搬瓦工官方明确说明DC9机房的所有中国方向流量分送到三条线路（电信CN2 GIA、移动CMIN2、联通Premium AS10099），CMIN2从2024年11月起对两个洛杉矶机房的所有E-commerce套餐开放。移动用户买GIA-E走的就是CMIN2，这一点有官方页面背书。
